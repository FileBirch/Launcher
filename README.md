# FileBirch read-only preview

This local preview opens XLSX, ODS and UTF-8 CSV in Tables; DOCX, ODT and UTF-8 TXT in Papers; and PPTX and ODP in Present. To try it on Windows, double-click Start FileBirch.cmd (requires Node.js 24), keep its window open, and open http://127.0.0.1:4286/ in your browser. For an overview of supported features and limits, see START-HERE.txt in the preview package.
